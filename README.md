# VexInclinator

**Zero-fee all-in-one Solana wallet cleaner.** Ready for public use.

Reclaim **100%** of locked SOL from empty token accounts. No fees. Non-custodial. Open source.

## Features
- Close empty SPL & Token-2022 accounts → full rent back (0% fee)
- Multi-wallet support (Phantom, Solflare, Backpack, Glow and more)
- Public claim leaderboard (protocol-tracked via on-chain memos)
- Batch operations with progress
- Multi-wallet read-only scan
- Clean professional UI
